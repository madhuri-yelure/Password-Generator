# Password Generator

A responsive Password Generator web application built using HTML, CSS, and JavaScript that generates strong, secure, and customizable passwords with a clean and user-friendly interface.

## Features

- Generate strong and secure passwords
- Customize password length
- Include uppercase letters
- Include lowercase letters
- Include numbers and symbols
- One-click password copy
- Responsive and modern user interface

## Technologies Used

- HTML
- CSS
- JavaScript
